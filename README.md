# 🧠 Quiz App

A simple and interactive **Quiz Application** built using **HTML, CSS, and JavaScript**. Users can answer multiple-choice questions, track their score, and restart the quiz after completion.

## 🚀 Features

- 🧠 Multiple-choice quiz questions
- ✅ Instant correct/wrong answer indication
- 📊 Live score tracking
- 🔢 Question counter
- 🎉 Final score screen
- 🔄 Restart Quiz functionality
- 📱 Responsive design
- 🎨 Clean and modern user interface
- ⚡ No API key required

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Quiz logic and user interaction

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Start answering the questions.

You can also open `index.html` directly in a web browser.

## 🎯 How It Works

The quiz questions are stored in JavaScript as an array of objects.

When the user selects an answer:

- The selected answer is checked.
- The correct answer is highlighted.
- The score is updated.
- The user can move to the next question.

After all questions are completed, the final score and performance message are displayed.
